## 🔍 Detailed Repository Breakdowns

### [obra/superpowers](https://github.com/obra/superpowers.git)
- **Primary Stack:** Universal Agent Plugin / Markdown Skill Definitions / Shell & Node.js hooks
- **Category:** Agent Workflow & Developer Methodology (Antigravity, Claude Code, Cursor, Codex, etc.)
- **Problem It Solves:** 
  AI coding agents often jump straight to writing messy code without fully understanding specifications, skipping tests, or hallucinating fixes during bugs. `superpowers` equips the agent with systematic engineering workflows: brainstorming & spec extraction, test-driven development (TDD), subagent delegation, systematic root-cause debugging, and code verification before claiming a task is done.
- **Key Skills / Modules Inside:**
  1. `brainstorming`: Interviews you to establish clear requirements and specs before coding.
  2. `writing-plans` & `executing-plans`: Breaks projects down into small, digestible, verifiable steps.
  3. `test-driven-development`: Red-Green-Refactor testing discipline for both Python and JS/TS.
  4. `subagent-driven-development`: Orchestrating specialized parallel subtasks.
  5. `systematic-debugging`: Formulates hypotheses and traces logs/root causes before randomly patching code.
  6. `verification-before-completion`: Ensures everything builds and passes tests before finishing.
- **When & How to Use This in Your Projects:**
  - **As an Antigravity Plugin:** You can install it directly into your Antigravity environment via:
    ```bash
    agy plugin install https://github.com/obra/superpowers
    ```
    or copy specific skills into `.agents/skills/` within any project repository.
  - **In Next.js + Python Projects:** When building your apps in this workspace, we use these exact principles:
    1. First define clear data schemas & API specs.
    2. Write unit tests (e.g. Pytest for Python backend, Vitest/Jest for Next.js frontend).
    3. Implement features incrementally.
    4. Run systematic verification on both running servers before moving code to production.

### [morluto/rea](https://github.com/morluto/rea.git)
- **Primary Stack:** TypeScript / Node.js MCP Server & CLI / Native Disassembler Bridges
- **Category:** Reverse Engineering Tool / MCP Server (Model Context Protocol) / Feature Deconstruction
- **Problem It Solves:**
  You see an impressive feature in an existing app or website (e.g., Notion's clipboard handler, Discord's voice protocol, Spotify's cache structure, or a competitor's complex web app/algorithm), but don't have their source code. REA allows you or your AI agent to inspect closed binaries, Electron apps, JS bundles, network packets, or local SQLite databases to understand the exact implementation down to the logic level, extract how it works, and build a clean version for your own app.
- **Key Modules & Capabilities:**
  1. `analyze-javascript-application`: Deconstructs bundled web apps, Next.js sites, Electron apps, ASAR archives, extracting routes, IPC calls, and modules.
  2. `inspect_website` & `web-network-captures`: Analyzes network payloads, API headers, and page structures.
  3. `inspect_sqlite_database`: Inspects local schema, triggers, WAL files, and caches.
  4. `native-analysis`: Hooks into Ghidra, Hopper, or IDA to inspect binaries (.exe, .dll, ELF).
  5. `reconstruction`: Turns reversed logic into clean, production-ready code for your project.
- **When to Use This Blueprint / Tool:**
  - When you want to **clone or recreate an existing application feature** (frontend UI logic, backend API structures, or internal protocols).
  - When analyzing third-party APIs or undocumented client-server communication to build a matching Python or Next.js service.
- **How to Install / Run:**
  - Quick setup for agent MCP:
    ```bash
    npx -y rea-agents@latest setup
    ```
  - Direct CLI inspection:
    ```bash
    npx -y rea-agents@latest analyze-javascript-application <path-to-app-or-bundle> --json
    ```

- **Category:** Cross-Platform Desktop & Headless Video Editor / Media Automation Engine

  Creating high quality video content (cinematic trailers, explainer shorts, Pixar-style animations, product demos, history documentaries) usually requires orchestrating multiple disparate AI models (image gens, video gens like Kling/Veo, voiceover narration like Chirp/ElevenLabs, captioning, music) and manually editing them in premiere.   3. `Remotion Composer (React / TypeScript)`: In `remotion-composer/`, video compositions, text kinetic motion, and transitions are written as React components and rendered to MP4.

- **When to Use This Blueprint:**
  - **Ideal blueprint for a Next.js + Python Web App**:

    - Connect to a **Python backend**: Implements OpenMontage's pipeline architecture to orchestrate scene scripts, call TTS/video APIs, and trigger Remotion/FFmpeg renders.
- **Setup & Execution:**
  - Python dependencies: `pip install -r requirements.txt`
  - Remotion composer: `cd remotion-composer && npm install`
  - CLI rendering demo: `python render_demo.py`

### [Oldcircle/geo-sleuth](https://github.com/Oldcircle/geo-sleuth.git)
- **Primary Stack:** Python 3.10+ / OpenStreetMap Overpass API / GDAL / Elevation DEM Data / OpenCV / Agent Skill
- **Category:** Geolocation AI Engine / OSINT Investigation Tool / Geospatial Analysis
- **Problem It Solves:**
  Reverse-engineering the physical location where a photograph was taken when there is **zero EXIF data, no GPS metadata, no street signs, and no famous landmarks**. Unlike standard reverse image search (which fails on generic landscapes or rural spots), `geo-sleuth` turns visual geometric clues (mountain ridge silhouettes, powerline angles, railway pier spacing, sun shadow angles, and flora) into mathematical queries against OpenStreetMap and global elevation models to pinpoint camera coordinates down to within ±2 meters.
- **Key Modules & Tools Inside:**
  1. `terrain.py`: Compares background mountain silhouettes against global digital elevation models (DEM) to generate ridge line fingerprints.
  2. `sun.py`: Computes solar position and azimuth from shadows to narrow down cardinal orientation and time of day.
  3. `osm.py`: Performs high-speed vector queries across OpenStreetMap (rail lines, bridges, rivers, roads, pylons).
  4. `match.py` & `pose.py`: Solves camera focal length, tilt, and perspective rays to match geometry mathematically.
  5. `evidence.py`: Generates satellite overlay images confirming the exact camera viewpoint and field of view.
- **When to Use This Blueprint:**
  - When building a **Next.js + Python OSINT or Geolocation App** (e.g., an automated Geoguessr solver, photo verification service, crime investigation tool, or environmental monitoring portal).
    - **Frontend (Next.js + Mapbox / Leaflet)**: Interactive map where users upload a photo, adjust confidence sliders, view candidate zones, and see the camera frustum / satellite evidence overlay.
    - **Backend (Python / FastAPI)**: Hosts `geo-sleuth`'s Python scripts as background tasks to process images, query OSM/terrain elevation grids, and stream real-time coordinate candidates back to the frontend.
- **Setup & Execution:**
  - Skill install: `npx skills add Oldcircle/geo-sleuth`
  - Python check: `python skills/geo-sleuth/scripts/doctor.py`
